laman ini berisi tahapan berlajar github seperti :
repo = nama folder project digithub
commit = rekaman atau snapshot pada sebuah commit/perubahan
hash = penanda atau karakter unit pada sebuah coomit/perubahan
checout = berpindah dari satu commit ke commit lain
branch = cabang bebas pada sebuah commit
merge = menggabungkkan beberapa branch
remote = sumber yang memiliki repo
clone = mengambil repo dari remote
push = pengirimkan commit ke repo
pull = mengambil commit dari repo
